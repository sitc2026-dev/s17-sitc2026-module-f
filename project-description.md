# Module F – SwapLoop Public Website (HTML/CSS)

## Brief (author notes)

**Module F** is the design-implementation module. Competitors may use **HTML and CSS only**. CSS frameworks such as **Tailwind** or **Bootstrap** are allowed.

### Scope

Build the **public-facing marketing site** for **SwapLoop** (the Shanghai community battery-swap / e-bike charging pilot). The site should introduce the SwapLoop community service and cover at least:

- overview of the service and how it works
- stations (discovery / what a station offers)
- offers for **individuals** (riders)
- offers for **delivery companies’ fleets**

Provide supporting assets (images, copy, icons, and optional video) for competitors to use while building the site.

### Quality expectations

- **Accessibility** and **SEO** best practices are required.
- The site must be **fully responsive** and implement **three breakpoints** (mobile, tablet, desktop).
- Include a small set of **challenging CSS tasks** (layout/CSS techniques beyond basic styling).
- Specify required **transitions and animations** as explicit expectations.
- **Avoid requiring too many repetitive tasks** (e.g. many near-identical cards or repeated blocks). JavaScript is not allowed, so competitors cannot generate repeated markup dynamically — keep required markup volume reasonable.
